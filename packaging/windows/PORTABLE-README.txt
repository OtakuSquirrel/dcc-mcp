DCC-MCP Portable for Windows x64
================================

1. Run dcc-mcp.exe.
2. Open http://127.0.0.1:18812/ in a browser.
3. Use the Install page to detect and install DCC connectors.
4. Point an MCP client at http://127.0.0.1:18812/mcp.

The daemon stores user configuration and managed-install manifests under:
    %USERPROFILE%\.dcc-mcp

Close the daemon console or press Ctrl+C to stop it.
